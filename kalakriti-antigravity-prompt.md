# Antigravity Prompt — Kalakriti Website Theme Overhaul

Redesign the entire visual theme of my website "Kalakriti" (a platform built to showcase talented individuals/artisans) using a heritage-luxury Indian aesthetic inspired by high-end sites like Indra Sarees & Jewels, Vyomarc Technologies, and Mahadi Henna. Combine the best elements of all three into one cohesive design system. Do not change existing content/functionality — only restyle.

## 1. Color Palette
- Primary: deep maroon / wine (#5C0E1E to #7A1B2E range)
- Accent: warm gold/brass (#C9A15A to #D4AF6A range)
- Background: warm ivory/cream (#F5EDE0)
- Text: near-black for body, gold for highlights/CTAs
- Use maroon as the dominant header/footer color with gold text and iconography

## 2. Typography
- Headings: elegant serif (e.g., Playfair Display or Cormorant) for a heritage, editorial feel
- Body/nav: clean modern sans-serif for readability
- Mix serif "hero statement" text with a highlighted accent word in gold (like "Rooted in **Purpose**" or "L'ÉLÉGANCE **INDIENNE**")

## 3. Hero Section
- Full-width hero with a strong background image or illustration (Mughal arch silhouettes, domes, or a portrait-style hero image)
- Large serif headline + gold accent word
- Short supporting line beneath
- One primary CTA button in gold with maroon text, pill or slightly rounded

## 4. Category / Feature Circles
- Row of circular thumbnail images under the hero representing key sections (e.g., categories of talent/craft), each with a label and "View more →" link underneath
- Consistent circular crop with a thin gold ring border

## 5. Featured/Highlight Grid
- "New" or "Featured" badge tags on cards (top-left corner, gold-on-maroon or maroon-on-gold)
- Card layout: image, title, subtitle/price-or-tag, consistent spacing
- Section heading centered with a decorative flourish/divider (small icon or ornamental line) above or below the title, similar to "NOS COUPS DE CŒUR"

## 6. Trust/Value Strip
- Horizontal strip with 4 icons + short labels (e.g., Quality, Fast Turnaround, Secure Process, Support) — icon in gold/line-art style, small caption text beneath

## 7. Ornamental Details
- Incorporate subtle mandala/paisley corner ornaments or border patterns (like Mahadi) on section dividers, footer, or card frames — used sparingly, not overwhelming the modern layout
- Thin gold decorative borders/frames around key images

## 8. Split Banner Section
- Two-column full-bleed image banners with overlay text + CTA, one for each major offering/category, dark overlay with gold CTA button

## 9. Social Proof / Gallery
- Instagram-style scrolling image grid near the footer with handle/tag callout

## 10. Footer
- Maroon background, gold text, logo + tagline on the left, link columns (About, Support, Legal), newsletter signup with gold "Subscribe" button, social icons

## 11. Overall Feel
- Should feel premium, warm, and rooted in Indian craft heritage — not childish or overly colorful — think boutique/luxury brand rather than generic marketplace
- Fully responsive: mobile view should stack sections cleanly and keep the ornamental details lightweight so they don't slow load times

## 12. Technical Notes
- Use CSS variables for the color palette so theming is easy to adjust later
- Keep existing page structure/routes intact — this is a visual/theme pass, not a rebuild
- Ensure accessibility: sufficient contrast between gold text and maroon backgrounds
